# Contributing Guidelines  

We welcome contributions to this project! Please follow these guidelines:  

## Getting Started  
- Fork the repository and create your feature branch from `main`.  
- Ensure you have the necessary development environment set up (Python, Node, Docker).  

## Code Style  
- Use PEP8 standards for Python code and format using Black.  
- Write clear, descriptive commit messages.  
- Include docstrings and type hints where appropriate.  

## Pull Requests  
- Use descriptive titles.  
- Link related issues (e.g., closes #123).  
- Ensure CI checks pass.  
- Provide tests for new functionality.  
- Address reviewer feedback promptly.  

## Reporting Issues  
- Use the **Bug Report** issue template for bugs.  
- Use the **Feature Request** template to propose new features.  
- Provide clear steps to reproduce issues with relevant details.  

Thank you for your contribution!
